AI with Paul26

영상 · 레퍼런스

잘 된 영상 하나가 편집 양식이 돼요

레퍼런스 없이 "릴스 만들어줘"만 하면 AI는 무난한 영상을 만들어요.

레퍼런스는 둘 중 하나로

  • 링크로 — 다른 사람의 잘 된 세무 릴스 주소
  • 첨부파일로 — 세무사님이 예전에 만드신 영상

오늘 할 일

이 레퍼런스의 편집 양식(컷 길이·자막 위치·훅 방식)을 뽑아서, 오늘 올릴 영상 편집에 그대로 적용해요.

AI with Paul27

영상 · 2-1 레퍼런스 분석 · 프롬프트

레퍼런스의 편집 양식을 뽑아요

2-1 레퍼런스 분석하기
이 영상을 레퍼런스로 분석해줘. [레퍼런스 영상 링크 또는 첨부파일]
길이, 컷 길이, 첫 1~2초 훅 방식, 자막 위치·크기·색, 장면 순서를
표로 정리해서 레퍼런스_양식.md로 저장해줘.

링크가 안 열리면 영상을 다운받아 첨부파일로 올려줘도 돼요. 세무사님이 예전에 만드신 영상을 레퍼런스로 써도 좋아요.

AI with Paul28

영상 · 2-2 편집기 사이트 · 프롬프트

레퍼런스 양식대로 자동 편집하는 화면을 만들어요

2-2 나만의 영상 편집기 만들기
레퍼런스_양식.md를 바탕으로 "나만의 영상 편집기" 웹 화면을 만들어줘.
ffmpeg가 없으면 먼저 설치를 도와줘(관리자 비밀번호 없이).
· 화면: 영상을 끌어다 놓는 칸 + [스토리보드 받기] 버튼
· 영상을 넣고 누르면, 레퍼런스_양식.md의 컷 길이·훅 방식대로
  장면 목록(시작·끝·자막)을 스토리보드로 보여줘
· 스토리보드에서 자막을 고치거나 장면을 빼고 [확정하고 만들기]를 누르면
  레퍼런스 양식 그대로 컷·자막·음악까지 입힌 영상이 만들어지게 해줘
· 다 되면 미리보기 자리에서 재생 + [내려받기] 버튼까지
먼저 화면만 만들고, 내 영상 하나로 테스트해봐.

만드는 데 10분 안팎 걸려요. 디자인은 "버튼을 더 크게"처럼 말로 바꿔요.

AI with Paul29

영상 · 2-3 써보기

영상 넣고, 스토리보드 보고, 확정해요

  1. 오늘 올릴 영상을 화면 칸에 끌어다 놓아요.
  2. [스토리보드 받기] → 레퍼런스 양식대로 장면 목록이 나와요.
  3. 자막을 내 말로 고치고, 마음에 안 드는 장면은 빼요.
  4. 마음에 들면 [확정하고 만들기] → 재생해서 확인해요.

막히면 Code 탭에 어디서 멈췄는지, 화면에 뭐가 보였는지 캡처와 같이 알려주세요.

영상 · 유튜브 자동 업로드

API는 프로그램용 문, 업로드엔 출입증이 필요해요

직접 올리기

  • 스튜디오를 열고 파일을 골라요
  • 제목·설명을 매번 붙여 넣어요
  • 영상이 많아지면 손이 많이 가요

API로 올리기

  • 유튜브의 정식 통로로 바로 보내요
  • 편집기 화면의 버튼 하나로 올라가요
  • 처음 한 번 내가 직접 허락(OAuth 출입증)해요

오늘 올리는 영상은 '비공개'로 올라가요.

구글 심사를 받지 않은 프로그램으로 올린 영상은 비공개로 고정돼요. 채널에 올라가는 것까지가 오늘 목표예요.

AI with Paul32

영상 · 3-1 구글 클라우드 준비

프로젝트·API·동의 화면을 만들어요

  1. console.cloud.google.com → 약관 동의(결제 정보는 넣지 않아요) → 새 프로젝트 taxcpa-upload.
  2. 검색창에 YouTube Data API v3 → 들어가서 사용.
  3. API 및 서비스 → OAuth 동의 화면 → 시작하기: 앱 이름 세무릴스 업로더, 이메일은 내 이메일, 대상 외부 → 동의 체크 → 만들기.
  4. 왼쪽 대상 → 테스트 사용자 → Add users에 유튜브 채널이 있는 내 이메일을 넣어요.

4번을 빼먹는 게 가장 흔한 실수예요. 빠지면 로그인할 때 '액세스 차단됨'이 떠요.

AI with Paul33

영상 · 3-2 출입증 파일

출입증 파일을 받아 폴더에 넣어요

  1. 왼쪽 클라이언트 → 클라이언트 만들기.
  2. 애플리케이션 유형은 데스크톱 앱, 이름은 그대로 두고 만들기.
  3. 뜬 창에서 JSON 다운로드를 눌러요. 이 창을 닫으면 다시 못 받아요.
  4. 받은 파일 이름을 client_secret.json으로 바꿔 세무사홈페이지 폴더에 넣어요.

이 파일은 비밀번호처럼 다뤄요. 남에게 보내거나 인터넷에 올리지 않아요.

AI with Paul34

영상 · 3-3 업로드 연결 · 프롬프트

편집기 화면에 유튜브 업로드 버튼을 붙여요

3-3 유튜브 자동 업로드 연결하기
client_secret.json 으로 유튜브 자동 업로드를 연결해줘.
· 나만의 영상 편집기 화면에서 영상이 만들어지면 그 아래에
  제목·설명 칸과 [유튜브에 올리기] 버튼을 추가해줘.
· 처음 실행할 때 브라우저로 구글 로그인을 띄우고, 출입증은 token.json에 저장해서
  다음부터는 로그인 없이. 권한은 업로드에 필요한 것만.
· 공개 범위는 비공개 고정, 올리는 동안 진행 표시, 끝나면 영상 주소.
다 되면 방금 만든 영상을 비공개로 한 번 올려서 로그인을 끝내봐.

처음 올릴 때 브라우저에 구글 로그인 창이 떠요. 계정 선택 → 테스트 사용자로 넣은 계정 → '안전하지 않음' 경고가 떠도 계속 진행하면 돼요.
